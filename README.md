### 🔐 Distributed Flash Sale Inventory Lock

[![GitHub](https://img.shields.io/badge/GitHub-Repository-181717?style=for-the-badge&logo=github)](https://github.com/Amit23ds/flash-sale-inventory-lock)

**Spring Boot • Redis/Redisson • MySQL • Docker • JMeter**

- Prevents inventory overselling using Redis distributed locking.
- Tested with **100 concurrent JMeter requests against 10 units of stock with zero oversells**.
- Implements fail-fast handling for lock contention and out-of-stock scenarios.
- Returns appropriate `409 Conflict` and `429 Too Many Requests` responses.
- Includes unit and integration testing with JUnit 5, Mockito and Testcontainers.

### 🤖 DevPilot — GitHub RAG Code Assistant

[![GitHub](https://img.shields.io/badge/GitHub-Repository-181717?style=for-the-badge&logo=github)](https://github.com/Amit23ds/DevPilot)

**Java • Spring Boot • Next.js • Gemini • PostgreSQL/pgvector • GitHub OAuth • SSE**

- Built a GitHub-backed RAG code assistant for natural-language repository queries.
- Implemented GitHub OAuth and an asynchronous repository indexing pipeline.
- Used code filtering, token-based chunking, Gemini embeddings and pgvector.
- Implemented HNSW-based semantic retrieval.
- Built real-time streamed responses using SSE.
- Indexed **9 repositories, 219 files and 994 code chunks**.
